# CORTEX Image Generation Handoff

This folder contains the upload-ready packages for generating the final real image assets for the 50-visual library.

## Workflow

- Open 5 fresh GPT Thinking chats.
- Upload exactly one batch zip into each chat.
- Use the batch-specific bridging prompt to connect the chat to the prompt file inside the zip.
- Generate exactly 10 final image assets per batch.
- Keep the output image-first, not text-first.
