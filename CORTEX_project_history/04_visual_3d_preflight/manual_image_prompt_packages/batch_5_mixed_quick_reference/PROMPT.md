# CORTEX Manual Image Generation Prompt Package

Paket ini dipakai untuk membuat 10 gambar final per batch secara manual di GPT Thinking atau image model lain berbasis GPT Image.

Tujuan:
- Hasil gambar asli, bukan teks saja.
- Tetap satu keluarga visual dengan CORTEX.
- Semua label dan isi gambar memakai Bahasa Indonesia, kecuali istilah medis yang lebih tepat dipertahankan dalam bahasa aslinya.
- Kreativitas boleh maksimal, tapi tetap harus klinis, elegan, dan mudah dipindai di mobile.

## Batch 5 / Mixed Quick Reference

### Scope
- Generate exactly 10 final image assets for Batch 5 / Mixed Quick Reference.
- Use the asset briefs in `ASSET_BRIEFS.json` as the only batch reference.
- Do not mix with other batches.
- Use the same CORTEX liquid-glass medical DNA that already exists in the project.
- Visual voice target: ringkas, sangat elegan, feel like mobile cheat sheet / quick reference cards / atlas ringkas.

### Creative direction
- Make the visuals feel like finished app assets, not slide screenshots.
- Prioritize strong composition, mobile readability, and premium spacing.
- Use medium-weight line art and elegant glass panels.
- Keep diagrams scannable and visually disciplined.
- If a visual is a comparison, make the contrast instantly obvious.
- If a visual is a flowchart, make the sequence readable at a glance.
- If a visual is a poster, give it a hero composition with a clear focal point.
- If a visual is a reference strip, make it compact but still luxurious.

### Language rule
- All visible labels should be Bahasa Indonesia unless the term is medically more exact in English or already standard in medical education.
- Avoid English-heavy headings or captions.
- If you must use an English medical term, keep the surrounding explanation in Bahasa Indonesia.

### Non-negotiable quality bar
- No text-only frames.
- No empty placeholder cards.
- No lazy generic infographic look.
- No clutter that breaks mobile readability.
- No cartoon style.
- No clipart-like anatomy.
- No tiny unreadable paragraphs.
- No visual mixing from other batches.

### If the prompt leaves room for creativity
- Push the composition further, but keep the medical meaning exact.
- Add subtle visual hierarchy, depth, and premium material treatment.
- Use composition to communicate the clinical idea, not just text labels.

### Output expectation
- Create the 10 final image assets in the same order as the asset briefs.
- Keep the deliverable image-first.
- If the platform supports it, give only a short confirmation after generation.
