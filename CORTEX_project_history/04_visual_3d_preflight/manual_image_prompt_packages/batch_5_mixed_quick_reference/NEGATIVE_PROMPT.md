# Negative Prompt

Use this to avoid weak or off-brief outputs.

- text-only layout
- empty placeholder frame
- generic stock infographic
- cartoon style
- childish illustration
- overly thin lines
- overly bold lines
- cluttered composition
- unreadable microtext
- mixed languages in labels
- English-heavy title cards
- messy medical annotation
- irrelevant anatomy
- random icons
- low contrast
- muddy background
- flat uninspired card design
- slide screenshot look
- poster promotion look
- overdecorated glow
- blurry typography
- cropped subject
- bad spacing
- visual noise
- duplicate panels without meaning
- unrelated symbols or decorative flourishes
