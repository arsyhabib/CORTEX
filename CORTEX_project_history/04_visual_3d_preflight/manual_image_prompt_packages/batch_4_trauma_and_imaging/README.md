# Batch 4 / Trauma and Imaging Manual Image Package

This package is for manual image generation using GPT Thinking or GPT Image-based tools.

## Files
- `PROMPT.md`
- `BRIDGING_PROMPT.md`
- `NEGATIVE_PROMPT.md`
- `ASSET_BRIEFS.json`
- `ASSET_BRIEFS.md`
- `OUTPUT_SPEC.md`

## How to use
1. Open a fresh GPT Thinking chat.
2. Upload this zip.
3. Paste the bridging prompt if you want a short reminder.
4. Generate the 10 final image assets in order.
5. Keep all visible labels in Bahasa Indonesia unless a technical English term is necessary.

## Batch scope
- Batch 4 / Trauma and Imaging
- 10 assets exactly
- no cross-batch mixing
- image generation only
