# Kimi Agent Instructions

You are filling content for the CORTEX education shell.

## What you may edit

- Files in `templates/`
- Files in `working/`
- QC report files
- content manifests

## What you must not edit

- `index.html`
- `404.html`
- shell source files
- theme / motion implementation

## Output expectations

- Keep content structured and modular.
- Prefer short, readable sections with clear IDs.
- Reference visuals through manifest IDs.
- Keep quiz, glossary, flashcards, and 3D refs separate from prose.
- Do not insert API keys.
- Do not inline large assets.

## Quality rules

- Use consistent IDs.
- Keep summary fields short.
- Ensure page mappings are valid.
- Write content that can be rendered lazily and independently.
